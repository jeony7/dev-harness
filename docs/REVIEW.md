## 실행한 검사

명령·종료 코드·출력 요약, 직접 조작한 입력·행동·기대 결과·실제 결과를 적습니다. 실행하지 못한 검사는 사유를 기록합니다. lint 성공을 기능 통과로 바꾸지 않습니다.

같은 코드·설정·의존성·입력·환경과 검사 범위에서 얻은 유효한 기존 결과는 근거 위치를 참조해 재사용합니다. 재사용한 근거와 이번에 실행한 검사를 구분하고, 변경·실패·불확실성의 영향을 받거나 미확인인 흐름은 검증합니다.

에이전트를 나눠 작업했다면 검사 담당·대상 코드·부분 검사인지 최종 통합 검사인지 구분합니다. 서버·프론트 연결, 임시 응답 사용 여부, 중요한 실패 흐름의 실제 결과를 기록하고 코드 변경의 영향을 받은 검사는 다시 확인합니다. 도구의 실행 기능이 없어 사용자가 검사를 수행했다면 제공받은 결과임을 표시합니다.
