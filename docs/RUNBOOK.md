# 실행·운영 안내

이 문서는 생성할 서비스의 실행 설명입니다. 아직 서비스 기능의 완료를 뜻하지 않습니다.

- 선택 스택과 필요한 버전:
- 의존성 설치 명령:
- 빌드 명령:
- 실행 명령:
- 바인딩 주소 / 포트 / 첫 경로:
- 상태 확인 경로:
- 종료·재실행 방법:

## 데이터와 AI

- 초기 데이터 생성 방법과 저장 위치:
- 재시작 후 데이터 유지 여부:
- 제품 내부 AI가 필요한지 / 실제 연결 방식 / 필요한 환경변수 이름:
- 실제 호출·모의 호출·미연결 구분:

키·토큰의 실제 값은 기록하지 않습니다.

## 핵심 검증 흐름

실제 입력 → 버튼/요청 → 기대 결과 → 관찰 결과를 관련 AC ID와 함께 적고 재현 절차를 남깁니다.

## 남은 기능과 한계

구현/미구현/미검증을 구분합니다. 프로젝트에서 지정한 배포·기동 방식이 있다면 해당 지침을 우선합니다.
